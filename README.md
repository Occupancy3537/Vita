# Vita

Макет PWA — AI health & wellness. Один HTML-файл, моковые данные, все анимации и переходы рабочие.

Открыть: `index.html` в браузере (или любой статический хостинг).

## Экраны
Четыре вкладки и одна модель: **Вопрос → Проверка → Привычка**.

- **Сегодня** — «что сделать сегодня и к чему это приведёт»: кругляши сегментов (цвет — по худшему критерию сегмента, тап — «Движение» или «Питание»), дуга с **прогнозом дня** («прогноз 82 · можно 86», корона — только у закрытого дня выше 80), одна главная мысль (что сделать, почему, одна кнопка, «Почему я так думаю»), «Вчера: моложе на N дня», «Решить» — входящие события одной карточкой + «ещё N», «Ещё сегодня» не больше двух строк (вечером — «Итог дня»), одна строка идущих проверок, привычки от врача с ручной отметкой, серии; стрелка к вчерашнему дню; по воскресеньям — неделя
- **Проверки** — путь «вопросы → проверки → вердикты → привычки»: что ждёт решения (вопросы с доказательствами «7 из 8 против 20%»), идущие проверки (ожидание и дата вердикта), сбор эпизодов, закрытые вердикты
- **Врач** — консилиум (запуск по вопросу, ход по шагам, итог семейного врача с действиями), заключение семейного врача, «Следующая сдача» (дата, цена, поводы, вопрос оптимизатора), свёрнутые состав · лаборатория · оптимизатор, медпаспорт
- **Я** — PhenoAge, драйверы, тренды, «Мои цели» с источником каждой цели, точка «вне референса»
- Оверлеи: Прогноз дня, Вклад дня, Почему я так думаю, Движение, Питание (БЖУ за день, источники белка, лимиты жиров и натрия, микро за неделю), Консилиум, Открытие, Проверка, Серии, Мои цели, Восстановление, Сон, Наука недели, Медпаспорт (системы организма, грейды, «Спросить об этом»), «Все состояния»

## Дизайн-язык
Oura × Longevity: светлая кремовая (#F7F6F3) и тёмная (#0F1214) темы, тонированные карточки с мягким свечением, бирюза как основной акцент + зелёный/янтарный/золото для статусов, коралл — для «требует внимания», Manrope 200–300 для цифр, Newsreader 300 для редакционных фраз, собственные line-иконки 1.5px (восход, маршрут, граф связей, спираль ДНК, волна ВСР и др.). Фон hero вшит в `index.html` — макет работает одним файлом. На десктопе в углу — «Все состояния», тема и вариант hero с фото горы. `prefers-reduced-motion` отключает анимации. Доступность: вторичный текст с контрастом не ниже 4.5:1, шрифт не мельче 11px, цели нажатия от 40px.

## План сборки
См. комментарий «ПЛАН СБОРКИ» в `<head>` файла `index.html`:
решения → intervention + expectation в системе; цели подчиняются медгейту;
вклад дня ≠ PhenoAge; доступ не по токену в URL; пустое = отсутствует;
п. 16 — новая архитектура, модель «Вопрос → Проверка → Привычка», индекс как прогноз.

## Данные
Бэкенд — ветка `card-service` (FastAPI + Postgres). Какое поле кормит какой блок «Сегодня» и чего не хватает в `/vita/today` — пп. 10–16 «ПЛАН СБОРКИ» в `index.html`.
