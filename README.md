# Vita

Макет PWA — AI health & wellness. Один HTML-файл, моковые данные, все анимации и переходы рабочие.

Открыть: `index.html` в браузере (или любой статический хостинг).

## Экраны
- **Сегодня / Ритм** — кольцо дня, чипы, нудж, «Нужен ты», воскресная наука; темп шагов и рычаги питания
- **План** — таймлайн панелей, анализы, оптимизатор, заключение врача, Программа
- **Кейсы** — активный кейс (аллергия), доказательства, закрытые кейсы
- **Я** — PhenoAge, драйверы, тренды
- Оверлеи: Сон, ВСР, Энергия, Питание, Наука недели, Заключение, «Все состояния»

## План сборки
См. комментарий «ПЛАН СБОРКИ» в `<head>` файла `index.html`:
решения → intervention + expectation в системе; цели подчиняются медгейту;
вклад дня ≠ PhenoAge; доступ не по токену в URL; пустое = отсутствует.
