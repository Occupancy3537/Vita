# Vita

Макет PWA — AI health & wellness. Один HTML-файл, моковые данные, все анимации и переходы рабочие.

Открыть: `index.html` в браузере (или любой статический хостинг).

## Экраны
- **Сегодня** — «что сделать сегодня для долгой жизни и получается ли»: чипы-баллы, цветок биовозраста (лепестки — факторы дня), открытие-гипотеза с проверкой, «Нужен ты», брифинг из 2–4 подсказок, назначения по спине (неделя), серии с паузой, заморозками и режимом поездки
- **Ритм** — темп шагов, БЖУ за день, рычаги с источниками по блюдам, микронутриенты за неделю с советом
- **План** — сдача крови по поводам (невролог, PhenoAge, кардиолог), цена и выбор лаборатории, пробирки, оптимизатор, заключение врача, Программа
- **Кейсы** — активный кейс (аллергия), доказательства, закрытые кейсы
- **Я** — PhenoAge, драйверы, тренды
- Оверлеи: Открытие, Вклад дня, Восстановление, Сон, Питание, Наука недели, Заключение, Медпаспорт (системы организма, грейды, «Спросить об этом»), «Все состояния»

## Дизайн-язык
Oura × Longevity: светлая кремовая (#F7F6F3) и тёмная (#0F1214) темы, тонированные карточки с мягким свечением, бирюза как основной акцент + зелёный/янтарный/золото для статусов, коралл — для «требует внимания», Manrope 200–300 для цифр, Newsreader 300 для редакционных фраз, собственные line-иконки 1.5px (восход, маршрут, граф связей, спираль ДНК, волна ВСР и др.). Фон hero — `img/mountain.jpg`. На десктопе в углу — «Все состояния», тема и вариант hero с фото горы. `prefers-reduced-motion` отключает анимации.

## План сборки
См. комментарий «ПЛАН СБОРКИ» в `<head>` файла `index.html`:
решения → intervention + expectation в системе; цели подчиняются медгейту;
вклад дня ≠ PhenoAge; доступ не по токену в URL; пустое = отсутствует.

## Заглушки
`t.me/vita_doctor_bot` и названия исследований — моки.

## Данные
Бэкенд — ветка `card-service` (FastAPI + Postgres). Какое поле кормит какой блок «Сегодня» и чего не хватает в `/vita/today` — пп. 10–13 «ПЛАН СБОРКИ» в `index.html`.
