# Vita

Макет PWA — AI health & wellness. Один HTML-файл, моковые данные, все анимации и переходы рабочие.

Открыть: `index.html` в браузере (или любой статический хостинг).

## Экраны
Четыре вкладки и одна модель: **Вопрос → Проверка → Привычка**. Главная — взгляд и вывод, подробности — по тапу.

- **Сегодня** — кругляши сегментов (цвет — по худшему критерию, тап — «Движение» или «Питание»), дуга с прогнозом дня, слово-вердикт («Всё хорошо», «Можно улучшить», «Важно», «Нет данных», «День закрыт») и одно действие со стрелкой к прогнозу («Ужин без соли → 86»). Тап по действию — шторка: цифра, полоса лимита с прогнозом к ночи, откуда, что даст, ещё можно, что в норме. Ниже — строка «Решить» (если есть) и серии кольцами
- **Проверки** — переключатель «Вопросы · Проверки · Привычки»: решения с доказательствами, идущие проверки с кольцом прогресса, привычки врача по дням недели и вердикты
- **Врач** — консилиум, заключение семейного врача, медпаспорт — строками; карточка следующей сдачи; «Что сдаём» — состав, лаборатория и цена, оптимизатор
- **Я** — паспортный и биологический возраст рядом, лесенка PhenoAge, «Что дало» (образ жизни за 30 дней по факторам и вклад 9 маркеров крови), системы органов, тренды, цели, серии
- Шторки: Сегодня (по заголовку), Решить, Прогноз дня, Неделя, Движение, Питание (лимиты полосой с зоной перебора, микро — тепловая карта недели), Вклад дня, Почему я так думаю, Серии, Консилиум, Вопрос, Проверка, Открытие, Сдача, Медпаспорт, Мои цели, «Все состояния»

## Дизайн-язык
Oura × Longevity, ДС v2 по бенчмарку wellness-дашбордов: светлая кремовая (#F7F6F3) и тёмная (#0F1214) темы, плоские белые карточки без свечений, тон — только в круге иконки, бирюза — акцент, янтарь — «можно улучшить», коралл — только клиника, одна строка списка и одна тёмная основная кнопка, без КАПСа, Manrope 200–300 для цифр, Newsreader 300 для редакционных фраз, собственные line-иконки 1.5px (восход, маршрут, граф связей, спираль ДНК, волна ВСР и др.). Фон hero вшит в `index.html` — макет работает одним файлом. На десктопе в углу — «Все состояния», тема и вариант hero с фото горы. `prefers-reduced-motion` отключает анимации. Доступность: вторичный текст с контрастом не ниже 4.5:1, шрифт не мельче 11px, цели нажатия от 40px.

## План сборки
См. комментарий «ПЛАН СБОРКИ» в `<head>` файла `index.html`:
решения → intervention + expectation в системе; цели подчиняются медгейту;
вклад дня ≠ PhenoAge; доступ не по токену в URL; пустое = отсутствует;
п. 16 — новая архитектура, модель «Вопрос → Проверка → Привычка», индекс как прогноз;
п. 17 — главная «взгляд и вывод», ДС v2 по бенчмарку.

## Заглушки

## Данные
Бэкенд — ветка `card-service` (FastAPI + Postgres). Какое поле кормит какой блок «Сегодня» и чего не хватает в `/vita/today` — пп. 10–17 «ПЛАН СБОРКИ» в `index.html`.
