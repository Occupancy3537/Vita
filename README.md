# Vita

Макет PWA — AI health & wellness. Один HTML-файл, моковые данные, все анимации и переходы рабочие.

Открыть: `index.html` в браузере (или любой статический хостинг).

## Экраны
- **Сегодня** — «что сделать сегодня и получается ли»: кругляши (зелёный — норма), дуга с индексом дня (тап — «из чего индекс»), фраза дня из состояния, «вчера −N дня к биовозрасту», один слот событий (решение, вердикт, анализы, открытие, сверка, сдача скоро), главная подсказка с «почему я так думаю», идёт проверка, назначения врача с ручной отметкой, серии одним рядом; стрелка к вчерашнему дню; по воскресеньям — недельный итог
- **Ритм** — темп шагов, БЖУ за день (источники белка по тапу), лимиты жиров и натрия с источниками, микронутриенты за неделю с советом
- **План** — карточка «Следующая сдача» (дата, цена, поводы), остальное — свёрнутые секции с точкой изменений: состав, лаборатория, оптимизатор, заключение врача, Программа, закрытые
- **Кейсы** — активный кейс (аллергия), доказательства, закрытые кейсы
- **Я** — PhenoAge, драйверы, тренды, «Мои цели» с источником каждой цели, точка «вне референса»
- Оверлеи: Из чего индекс, Открытие, Вклад дня, Почему я так думаю, Серии, Мои цели, Восстановление, Сон, Питание, Наука недели, Заключение, Медпаспорт (системы организма, грейды, «Спросить об этом»), «Все состояния»

## Дизайн-язык
Oura × Longevity: светлая кремовая (#F7F6F3) и тёмная (#0F1214) темы, тонированные карточки с мягким свечением, бирюза как основной акцент + зелёный/янтарный/золото для статусов, коралл — для «требует внимания», Manrope 200–300 для цифр, Newsreader 300 для редакционных фраз, собственные line-иконки 1.5px (восход, маршрут, граф связей, спираль ДНК, волна ВСР и др.). Фон hero вшит в `index.html` — макет работает одним файлом. На десктопе в углу — «Все состояния», тема и вариант hero с фото горы. `prefers-reduced-motion` отключает анимации.

## План сборки
См. комментарий «ПЛАН СБОРКИ» в `<head>` файла `index.html`:
решения → intervention + expectation в системе; цели подчиняются медгейту;
вклад дня ≠ PhenoAge; доступ не по токену в URL; пустое = отсутствует.

## Заглушки
`t.me/vita_doctor_bot` и названия исследований — моки.

## Данные
Бэкенд — ветка `card-service` (FastAPI + Postgres). Какое поле кормит какой блок «Сегодня» и чего не хватает в `/vita/today` — пп. 10–13 «ПЛАН СБОРКИ» в `index.html`.
