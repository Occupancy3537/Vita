# card-service

«Мозг» медицинской карты и всей продовой логики longevity-системы Влада — план П1–П8 из `../CARD_ARCHITECTURE_PLAN_2026-09-13.md`. Изначально росло рядом с n8n, пока каждый кусок не докажет паритет со старой системой; к 2026-09-21 миграция закрыта целиком — **n8n выведен из эксплуатации**, card-service единственный оркестратор. Данные — Postgres (схема `card` — архитектура П1–П8 + операционное состояние; схема `health` — медданные, канон). Подробности текущего состояния всего проекта — в `../HANDOVER.md`.

## Статус

Продовый сервис, не скелет: ~55 модулей в `app/` — доктор (интейк, диспетчер, коммит), регистратор лабораторных документов, дневник питания (свой Telegram-бот, polling), 19 фоновых планировщиков/поллеров (советник, аномалии, дашборд-проверки, PhenoAge, климат, и т.д.), дашборд-эндпоинты для PWA. Полный список активных фич — в комментариях `run.sh` (по одному `*_ENABLED`-флагу на каждую).

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8080
```

Сервис слушает **только на 127.0.0.1**, и в проде, и локально — публично не торчит никогда. В проде наружу его отдаёт nginx (`/card/` → `127.0.0.1:8080`, дашборд-эндпоинты — свой `?token=` на каждый, nginx токены не разбирает).

## Деплой в проде

```bash
bash run.sh
```

Собирает образ и пересоздаёт контейнер (`--network pgnet --memory=192m`). Сам проверяет 13 обязательных секретов (`set -euo pipefail` + `: "${VAR:?...}"`) до сборки — падает с понятным сообщением, если что-то не задано, вместо тихого запуска с дырой. Секреты передаются через `-e VAR="$VAR"` из окружения шелла — никогда не хардкодятся в коде и не коммитятся.

**При редеплое с сохранением уже заданных секретов** — не реконструируй env наивным `docker inspect | sed 's/^/export /'`: значение с пробелом внутри (например, `YANDEX_IOT_TOKEN="Bearer <token>"`) при таком реэкспорте молча обрежется до первого слова. Квотируй через `shlex.quote()` при перестроении env-файла и после редеплоя сверяй живое значение (`docker exec card-service printenv VAR`), если менялся секрет такой формы.

## Тесты — обязательны перед любым деплоем

```bash
source .venv/bin/activate
pytest -q
```

Красный тест = не деплоим — тот же принцип, что раньше применялся к n8n-воркфлоу (parser-gate + syntax-check перед публикацией). На 2026-09-21: 697 passed, 0 failed. Тесты изолированы от боевой `health.*` через `REGISTRAR_HEALTH_SCHEMA=card_test` (`tests/conftest.py` поднимает card_test-двойники нужных таблиц) — падение теста никогда не пишет и не читает настоящую медкарту Влада.

## Структура

```
app/            # вся логика: main.py — FastAPI-роуты; doctor/ — интейк/диспетчер/коммит/поллер;
                # остальные модули — по одному на фичу/планировщик (1:1 с *_ENABLED в run.sh)
tests/          # pytest, 1:1 с app/ где возможно; conftest.py — изоляция от боевой health.*
```

## Почему отдельный git-репозиторий

Основной проект (`longevity-project/`) исторически не был git-репозиторием — патчи применялись точечными скриптами прямо к живой n8n/Postgres. card-service — новый код на новом языке, и с него дисциплина началась сразу: коммит на каждый осмысленный шаг, никаких прямых правок в обход git.
